% (6) Grenze der gewichteten Summe gegenueber Pareto
%     Die gewichtete Summe (Skalarisierung) findet je Gewichtung genau eine
%     Loesung, und zwar immer eine auf der konvexen Huelle der erreichbaren
%     Punktmenge. Pareto-optimale Plaene in einer Delle der Front sind fuer
%     KEIN Gewicht w optimal; beim Verschieben von w springt das Ergebnis
%     von einem Randpunkt zum anderen.
%     Gleiche Gewichte helfen NICHT. Gleiche Gewichte heissen "addiere beide Ziele gleich
%     stark", nicht "bevorzuge Ausgewogenheit". Eine Summe bewertet nur
%     den Gesamtwert, nicht die Verteilung auf die Teilziele. 
%
%     Abhilfe: Archiv:
%     Selektion bleibt bei der gewichteten Summe, zusaetzlich fuehrt der
%     Lauf eine Nebenliste, in die jedes bewertete Individuum aufgenommen
%     wird, das von keinem Eintrag dominiert wird. Entscheidend: Die Aufnahme entscheidet sich ueber Dominanz, nicht
%     ueber die gewichtete Summe, und Dominanz kennt keine Konvexitaet.
%     B landet also im Archiv, sobald es einmal erzeugt wurde.
%     Formulierung deshalb abschwaechen: nicht "grundsaetzlich
%     unerreichbar", sondern "wird nicht gezielt gesucht, aber festgehalten".
%     Grenze: Der Suchdruck kommt weiter allein von der gewichteten Summe,
%     das Archiv ist also nahe der Gewichtung dicht und anderswo duenn.
%     Eine gleichmaessig abgedeckte Front braucht dominanzbasierte
%     Selektion, z.B. NSGA-II (Eiben/Smith Kap. 12).
%     Nutzen fuer die Anwendung: Die reisende Person bekommt nicht nur
%     einen Plan, sondern Alternativen mit anderen Trade-offs. Genau das
%     nennen Eiben/Smith S. 196 als Vorteil gegenueber der Skalarisierung.
%
